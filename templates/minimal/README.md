# @PROJECT_NAME@

Set `PORT` before starting the API. The minimal profile intentionally does not
require database or JWT settings.

Minimal ASP.NET API generated by `aspnet-starter`.

This profile intentionally contains no user-service, users, roles, permissions, JWT authentication, Entity Framework Core, database, or third-party package dependency.

```bash
dotnet restore
dotnet build
dotnet run
```

Health check:

```bash
curl --fail http://localhost:5070/api/v1/health
```

Metrics are available at `/metrics`, and every response includes an
`X-Trace-Id` correlation header. Sentry and other exporters can be added later
without changing the application endpoints.
